# Motion, animation and motion graphics

Full vocabulary for anything that moves on a page. Three layers: **web animation types** (what you build), **cinematic techniques** (how film names the same ideas), and **the bridge** between them.

Sources verified 27 Nov 2026: technique names from [eyecannndy.com](https://eyecannndy.com) (130+ visual techniques), effect vocabulary from [ui.aceternity.com](https://ui.aceternity.com/components) and [react-bits](https://github.com/DavidHDev/react-bits), trend tags from [awwwards.com](https://www.awwwards.com/websites/). Names and concepts only — no content reproduced.

## 1. Web animation — the complete taxonomy

### By trigger

| Trigger | What fires it | Typical use |
|---|---|---|
| **On load** | Page ready | Hero entrance, staggered nav |
| **On scroll (reveal)** | Element enters viewport | Section reveals, fade-ups |
| **Scroll-linked (scrubbed)** | Tied to scroll position | Product tours, timelines, 3D sequences |
| **Sticky / pinned** | Element holds while page scrolls past | Scroll-telling, feature walkthroughs |
| **On hover** | Pointer over | Cards, buttons, nav |
| **On cursor move** | Pointer position anywhere | Parallax, magnetic, spotlight, trails |
| **On click / tap** | Interaction | Ripple, state change, expand |
| **On state change** | Data or route change | Loading, success, error, route transition |
| **Ambient / idle** | Always running | Backgrounds, gradients, particles |
| **On drag** | Pointer held and moved | Sliders, comparison, draggable cards |
| **On viewport resize** | Breakpoint cross | Layout morph |

### By what moves

**Transform** — translate, scale, rotate, skew, 3D rotate (rotateX/Y/Z), perspective
**Opacity / visibility** — fade, cross-fade, staggered opacity
**Clip and mask** — wipe, iris, shape reveal, text mask, SVG mask
**Filter** — blur, brightness, saturation, hue-rotate, grayscale, contrast
**Path** — motion along SVG path, draw-on stroke, morph between shapes
**Color** — gradient position, hue cycling, background shift
**Layout** — FLIP (position/size morph), shared-element transition, reflow
**Text** — per-character, per-word, per-line splits
**Canvas / WebGL** — shaders, particles, displacement, fluid, noise fields
**Physics** — spring, inertia, gravity, collision, magnetism

## 3. The bridge — cinematic → web

This is the useful part. Each film technique has a web equivalent you can actually build.

### Camera moves become scroll behavior

| Cinematic | On a web page | Build with |
|---|---|---|
| **Dolly** | Scroll-linked forward motion into the scene | ScrollTrigger scrub + scale/translateZ |
| **Dolly Zoom** | Background scales while foreground holds — vertigo | Two layers, opposite scale, scrubbed |
| **Pan / Whip Pan** | Horizontal scroll section; fast wipe between sections | Horizontal ScrollTrigger; snap transition |
| **Tilt** | Vertical reveal as you scroll into a section | translateY + opacity on entry |
| **Tracking / Trucking** | Sticky element travelling alongside content | `position: sticky` + scrubbed translate |
| **Pedestal** | Parallax layer rising at a different rate | Multi-speed parallax |
| **Arc** | Element following a curved path | `offset-path` or GSAP MotionPath |
| **Fixed Cam / Locked-On** | Pinned section, content moves inside it | ScrollTrigger pin |
| **Handheld** | Subtle continuous jitter — life, imperfection | Low-amplitude noise on transform |
| **Bolt Cam** | Hard snap between two states | Short duration, `steps()` easing |
| **Pass Through / Object Portal** | Camera enters an object, next section emerges | Mask scale-up transition |
| **FPV Drone** | Continuous scroll-through of a 3D space | Three.js camera on scroll |
| **Bullet Time** | Scroll scrubs a 360° orbit of a product | Image sequence or WebGL orbit |
| **Snorricam** | Element locked to cursor while world moves | Fixed element + inverse parallax |

### Cuts become section transitions

| Cinematic | On a web page |
|---|---|
| **Match Cut** | Shared-element transition — a shape persists while content swaps (FLIP) |
| **Jump Cut** | Abrupt state change, no tween — deliberate roughness |
| **Flash Cut** | White/color flash covering a swap |
| **Crash cut** | Hard snap with an audio-less impact feel; pair with scale punch |
| **Quick Cuts** | Rapid sequence of frames; stagger at 60–80ms |
| **Match motion** | Next section enters on the same vector the previous left |
| **Match Split** | Split-screen halves that stay continuous across a change |
| **Set Transition** | Full scene swap — curtain, wipe, mask |

### Time becomes easing and loops

| Cinematic | On a web page |
|---|---|
| **Slow Motion** | Long duration, ease-out — gravity |
| **Fast Motion** | Short duration, ease-in — urgency |
| **Speed Ramp** | Custom cubic-bezier that accelerates then holds |
| **Freeze Frame** | Animation pauses when scroll stops |
| **Stutter / Step-print** | `steps()` easing — mechanical, retro |
| **Stop Motion** | Frame-by-frame at low fps, deliberately |
| **Boomerang / Infinite Loop** | `yoyo: true` / seamless loop |
| **Zoetrope** | Sequence cycling in place |

### Optical effects become filters and shaders

| Cinematic | On a web page |
|---|---|
| **Motion Blur** | Blur proportional to velocity during fast transforms |
| **Halation** | Glow bleed around bright elements |
| **Haze / Vignette** | Radial gradient overlay; focuses attention |
| **Datamosh** | Glitch transition between sections |
| **Double Exposure** | `mix-blend-mode` layered imagery |
| **Slit-scan** | Scroll-driven horizontal displacement of an image |
| **Kaleidoscope** | Mirrored symmetry shader |
| **Color Shift** | Animated `hue-rotate` or gradient position |
| **Tilt Shift / Shallow Focus** | Selective blur — depth of field |
| **Focal shift** | Blur moves between foreground and background on scroll |
| **Morphing** | SVG path morph between shapes |
| **Masking** | Clip-path or SVG mask reveal |
| **Reflections** | Mirrored copy with gradient fade |
| **Thermal / Night Vision / X-Ray** | Full-page filter treatments as art direction |
| **Echo print / Duplication** | Ghost trails behind a moving element |

### Framing becomes layout

| Cinematic | On a web page |
|---|---|
| **Central Framing** | Centered hero, symmetrical |
| **Dutch Angle** | Rotated section — tension, deliberate unease |
| **Split Screen** | Two-column with independent scroll |
| **Screen in Screen** | Picture-in-picture, floating video |
| **Tableau** | Static composed scene — no motion, everything placed |
| **Close-Up / Wide shot** | Image crop strategy across the page |
| **Silhouette** | High-contrast cutout treatment |
| **Void** | Extreme negative space |
| **Shadow Box** | Framed, inset element with depth |

## 4. Rules that do not change

**Motion must do one of four things** — orient, sequence, confirm, or characterize. Decoration that does none is the clearest tell of generated design.

**One hero moment per page.** Spend the budget in the first viewport, then get quiet. Scattered hover effects on every card read as noise; one orchestrated entrance reads as intent.

**Timing defaults** — 150–250ms for user-triggered; 400–800ms for narrative entry; 40–80ms stagger between siblings; past six items stagger the group, not the item.

**Entry, not ambient.** Animate things as they arrive. Continuous ambient motion competes with reading.

**`prefers-reduced-motion`, always.** Replace movement with a fade — never with nothing.

**Test throttled.** If motion makes the page feel slower rather than more alive, it is decoration. Cut it.

## 5. Implementation

| Stack | Reach for |
|---|---|
| Single-file HTML | GSAP + ScrollTrigger; Lenis for smooth scroll |
| React / Next | Motion (Framer Motion); `react-bits`; Aceternity UI |
| Simple state change | CSS transitions — do not import a library for a fade |
| Shaders, particles, 3D | Three.js, or WebGL via a component library |
| Vector sequences | Lottie |
| Scroll smoothing | Lenis, Locomotive Scroll |
