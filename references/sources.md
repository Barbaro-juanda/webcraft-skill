# Reference sources

How to use design galleries without producing a copy of them. Taxonomies below were read from the live sites on 27 Nov 2026 — these are the sites' own label vocabularies, which are facts. No showcased work is reproduced.

## The rule

These sites hold **other people's copyrighted work**. Consult them live, extract *principles* and *vocabulary*, never reproduce content, layouts, copy or assets. A gallery tells you how a composition breathes and what the field currently calls things. It does not hand you a page to ship.

If the user asks for "a page like [site]", build from the underlying principle — rhythm, density, motion logic — and name what you took: "I used the staggered reveal and the oversized numerals, not their layout."

## Awwwards — the taxonomy worth knowing

The most useful thing here is not the showcased sites, it is the **filter vocabulary**. It is the industry's working list of what a web page can be classified as, and it makes requests precise.

**Award tiers** — Site of the Day (SOTD) · Site of the Month · Site of the Year · Honorable Mention (HM) · Nominee · Developer Award · and honors by discipline: Typography, No-code, E-commerce, Product, Portfolio, Business & Services

**Current trending labels** — Portfolio Websites · Animated websites · Scrolling · One page design · UI design · E-commerce layouts · Architecture websites · Photography websites · Free fonts

**Categories** — E-commerce · Architecture · Restaurant & Hotel · Design Agencies · Business & Corporate · Fashion · Mobile & Apps · Interaction Design · Illustration · Header Design · Art & Illustration · Culture & Education · Experimental · Film & TV · Food & Drink · Games & Entertainment · Luxury · Social responsibility · Web & Interactive (≈30 total)

**Style and technique tags** (≈85 total; the ones that describe a design decision):
Animation · Parallax · Fullscreen · Infinite Scroll · Horizontal Layout · Single page · Flat Design · Minimal · Clean · Colorful · Retro · Photographic · Big Background Images · Filters and Effects · Transitions · Microinteractions · Gestures · Unusual Navigation · Storytelling · Data Visualization · Typography · Web Fonts · Copy design · Responsive Design · Menu Horizontal · Menu Vertical · Navigation Menu · Header Design · Footer Design · Icons · Vector · Sound-Audio · 360 · 3D · VR · WebGL · Video · Gallery · Portfolio · Project Page · 404 pages · About Page · Contact Page · Forms and Input · Social Integration · Content architecture

**Technology labels** (≈170 total; the stack vocabulary): CSS animations · WebGL · React · Three.js · GSAP · Locomotive Scroll · Lottie · Swiper.js · Barba.js · Framer · Webflow · WordPress · Shopify · Figma

**Also filterable by** country (≈190), font (≈200), and color swatch. The font filter is genuinely useful: it answers "what typefaces are winning work using right now."

**Use it for:** composition risk, how far motion can go before it hurts usability, what "premium" currently signals, and the vocabulary above.
**Watch for:** most of it is portfolio-grade, built to win awards, not to convert. Do not import that cost into a client landing page without saying so out loud.
**Access:** the listing is readable logged out. A Pro tier exists for courses, and individual pages may differ.

## Cosmos — cosmos.so

A visual moodboard and inspiration tool. Collections are the organizing unit; it has **search by color**, **find similar elements**, and an AI-image toggle (Show / Blur / Hide). The real taxonomy lives behind **Explore**, which requires an account — the logged-out landing page carries only feature copy, no style vocabulary.

**Use it for:** palette and texture direction, cross-medium reference (print, photography, product). The color search is the strongest feature for finding a palette direction fast.
**Note:** images belong to their creators. Use it to find and describe a direction in conversation, never as an asset source.

## eyecannndy.com

A library of 130+ named visual techniques, each with video examples. The vocabulary is the value — knowing a thing is called *slit-scan*, *datamosh* or *match cut* lets you request it precisely.

The full list, and the translation from each film technique to its web equivalent, is in **`motion.md`**. That bridge is the most useful thing extracted from any of these sites.

**Note:** the register is cinematic, not web — camera moves, lens effects, editing. It serves video work (`/hyperframes`, `remotion-*`) directly, and web work through the bridge table.

## ui.aceternity.com

Open-source React/Tailwind components built on Motion, shadcn-compatible. See **`aceternity.md`** for the catalog.

Unlike the galleries, this is **usable code**, not just reference. Check its license before shipping into client work.

## motionsites.ai

A library of **AI prompts** for generating websites, indexed by the effect each produces.

Categories: Sections · Hero · Landing Page · SaaS · Portfolio · 3D · Agency · Creative · Ecommerce · AI · Dashboard · Travel · Fashion · Interactive · Fintech

Entries are named by the effect rather than the client — *Card Tunnel*, *Particle Brain*, *Orbit Sphere*, *Shelf Hero*, *Print Gallery*. That naming convention is itself worth copying: **name a direction by its mechanic**, not by the brand.

**Access:** prompts appear to sit behind signup. The detail pages did not load during extraction, so only the taxonomy above is confirmed.

## Running a reference pass

When the user has no visual opinion yet:

1. **Ask what they like in any medium** — a magazine, a product, a film. Faster than scrolling a gallery.
2. **If nothing, propose two contrasting directions in words.** "Editorial and quiet" vs "dense and industrial." Easier to react to than a blank page.
3. **Open a gallery only to validate** a direction already chosen. Browsing for one produces pastiche.
4. **Bring back principles in writing:** "pages in this register run 3–4 sections, the type scale jumps hard between hero and body, motion only on entry."

## Browsing live

Read, extract, describe. Do not save their assets into the project and do not paste their markup. When something is genuinely reusable it is because it is open source — and then it comes from the repository with its license, not from the rendered page.
