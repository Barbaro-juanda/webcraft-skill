# Aceternity UI — component catalog

[ui.aceternity.com](https://ui.aceternity.com/components) — free copy-paste React components built with Tailwind CSS and Motion, shadcn-compatible. Catalog read 27 Nov 2026.

This is an **index**: component names and the effect each produces. No source code reproduced.

## License

Free components are copy-paste with their own terms; Pro blocks, templates and some categories sit behind an all-access plan. **Check [ui.aceternity.com/licence](https://ui.aceternity.com/licence) before shipping into paid client work** — the free/paid split is per-item and changes.

Marked **PRO** below = part of a paid block set.

## Install

```bash
npx shadcn@latest add https://ui.aceternity.com/registry/<component>.json
```

## Aceternity vs react-bits

Both are animated React component libraries. They overlap heavily — pick by project, not by preference.

| | Aceternity | react-bits |
|---|---|---|
| Install | shadcn CLI | jsrepo CLI |
| Built on | Tailwind + Motion | Varies; many are standalone |
| Strength | Section blocks, full page templates | Backgrounds, text effects, micro-interactions |
| Count | ~100 free + 200 PRO blocks | 221, all free |
| License | Free/PRO split per item | MIT + Commons Clause |
| Best for | Shipping a whole marketing page fast | Picking one distinctive effect |

**Do not mix both in one project** unless you have a reason. Two animation libraries doubles the bundle and the style will not agree with itself.
